# Kanban

Un tablero **por proyecto** con cuatro columnas: _Pendiente_, _En curso_, _Revisar_ y _Hecho_.

- **Lanzar sesión** en una tarjeta abre _Nueva sesión_ con el título y las notas como prompt inicial; al crearla, la
  tarjeta queda ligada a la sesión.
- Las tarjetas ligadas **se mueven solas**: _En curso_ mientras la sesión trabaja o espera, _Revisar_ cuando termina con
  cambios. Lo que muevas a _Hecho_ a mano no se vuelve a tocar.
- Arrastra y suelta para reordenar; el lápiz edita título y notas.

El tablero se guarda en la carpeta de datos de MOD0 (por proyecto), no dentro del repositorio.
